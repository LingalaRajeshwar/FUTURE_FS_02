# ClientFlow - Client Lead Management System

A mini CRM system developed as part of the Future Interns internship.

## Features

- Admin login authentication
- JWT-based API protection
- Add, view, edit and delete client leads
- Update lead status
- Search and filter leads
- Follow-up date management
- Notes management
- Dashboard statistics
- MongoDB data persistence

## Tech Stack

- React + Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- CSS
